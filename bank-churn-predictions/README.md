# Прогнозирование оттока клиента банка
## Описание проекта
Нужно спрогнозировать, уйдёт клиент из банка в ближайшее время или нет. Предоставлены исторические данные о поведении клиентов и расторжении договоров с банком.

## Выводы и результаты
Результаты

Были протестированы три модели классификации: Logistic Regression, Decision Tree и Random Forest. Для борьбы с дисбалансом классов использовалось upsampling.

Лучший результат показала модель Random Forest с параметрами max_depth=11, n_estimators=90 и threshold 0.5. Значение F1-score составило 0.62.

Анализ feature importance показал, что наиболее значимыми признаками для прогнозирования оттока являются возраст клиента и количество используемых банковских продуктов. Наличие кредитной карты и пол клиента оказались менее значимыми.

Бизнес-вывод: модель может использоваться для формирования списка клиентов с повышенным риском оттока. Это позволяет сфокусировать retention-активности на наиболее рискованных клиентах вместо работы со всей клиентской базой.
